# Changelog

## 0.1.0

First release, for Auric v0.5.

- Syntax coloring for `.aur` files, plus semantic coloring of functions,
  parameters, variables and constant-like globals.
- Live errors from a built-in port of the `aurc` lexer, parser and type checker,
  with `aurc`'s messages, reporting every error rather than only the first.
- Hover docs, autocomplete, signature help and snippets.
- *Auric: Build App* and *Auric: Show Generated C*, running the real `aurc`.
